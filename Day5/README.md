\# Day 5 - Count Occurrences



\## Problem

Count how many times a target element appears in an array.



\## Example



Array: \[2, 5, 2, 8, 2, 9]



Target: 2



Output: 3



\## Approach

\- Start the count from 0.

\- Traverse every element in the array.

\- If the element matches the target, increase the count.

\- Return the final count.



\## What I learned

\- Array traversal

\- Conditional statements

\- Counting occurrences

\- Using a counter variable



\## Time Complexity

O(n)



\## Space Complexity

O(1)
