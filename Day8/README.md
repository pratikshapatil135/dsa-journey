\# Day 8 - Find Second Largest Element



\## Problem

Find the second largest distinct element in an array.



\## Example



Array: \[12, 35, 1, 10, 34, 1]



Output: 34



\## Approach

\- Maintain two variables: largest and second largest.

\- Traverse the array once.

\- If an element is greater than the largest, update both variables.

\- Otherwise, update second largest when the element is between the two values.

\- Ignore duplicate values of the largest element.



\## What I learned

\- Finding the second largest element

\- Maintaining multiple variables

\- One-pass array traversal

\- Conditional logic



\## Time Complexity

O(n)



\## Space Complexity

O(1)
