\# Day 1 - Two Sum



\## Problem

Find two numbers in an array whose sum equals the target.



\## Example

Array: \[2, 7, 11, 15]

Target: 9



Output: \[0, 1]



\## What I learned

\- Python arrays

\- Nested loops

\- Indexing

\- Git and GitHub basics



\## Time Complexity

O(n²)



\## Space Complexity

O(1)
