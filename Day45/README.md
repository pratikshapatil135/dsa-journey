
# Day 45 - Valid Anagram

## Problem
Check whether two strings are anagrams.

## Approach
Convert both strings into sorted character lists.
If the lists are equal, the strings are anagrams.

## Example
Input: listen, silent
Output: True

Input: hello, world
Output: False

## Complexity
Time Complexity: O(n log n)
Space Complexity: O(n)

## Concepts Learned
- Strings
- Sorting
- Functions
- Comparing character frequencies
