# Day 3 - Binary Search

## Problem
Find the index of a target element in a sorted array using Binary Search.

## Example

Array: [10, 20, 30, 40, 50, 60, 70]

Target: 60

Output: 5

## What I learned

- Binary Search
- Sorted arrays
- Low, high and mid
- While loop
- Searching efficiently

## Time Complexity

O(log n)

## Space Complexity

O(1)
