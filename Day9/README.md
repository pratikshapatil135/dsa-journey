\# Day 9 - Check if Array is Sorted



\## Problem

Check whether an array is sorted in ascending order.



\## Example



Array: \[1, 2, 3, 4, 5]



Output: True



\## Approach

\- Start from the second element.

\- Compare each element with the previous element.

\- If an element is smaller than the previous element, the array is not sorted.

\- If no such element is found, the array is sorted.



\## What I learned

\- Comparing adjacent elements

\- Array traversal

\- Boolean values

\- Early return



\## Time Complexity

O(n)



\## Space Complexity

O(1)
