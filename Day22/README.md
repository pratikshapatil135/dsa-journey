\# Day 22 - Merge Two Sorted Arrays



\## Problem



Given two sorted arrays, merge them into one sorted array.



\## Example



Array 1: \[1, 3, 5, 7]



Array 2: \[2, 4, 6, 8]



Output: \[1, 2, 3, 4, 5, 6, 7, 8]



\## Approach



Use two pointers.



\- `i` points to the current element of the first array.

\- `j` points to the current element of the second array.

\- Compare both elements.

\- Add the smaller element to the result.

\- Move the corresponding pointer.

\- After one array is finished, add the remaining elements of the other array.



\## What I Learned



\- Two-pointer technique

\- Merging sorted arrays

\- Array traversal

\- Efficient comparison



\## Time Complexity



O(n + m)



\## Space Complexity



O(n + m)
