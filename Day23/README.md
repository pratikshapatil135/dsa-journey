\# Day 23 - Intersection of Two Arrays



\## Problem



Given two arrays, find the elements that are present in both arrays.



Each common element should appear only once in the result.



\## Example



Array 1: \[1, 2, 2, 1]



Array 2: \[2, 2, 3]



Output: \[2]



\## Approach



\- Convert the first array into a set.

\- Create an empty set for the result.

\- Traverse the second array.

\- If an element exists in the first set, add it to the result set.

\- Convert the result set into a list.



\## What I Learned



\- Python sets

\- Set membership

\- Intersection

\- Duplicate removal

\- Fast lookup



\## Time Complexity



O(n + m)



\## Space Complexity



O(n)
