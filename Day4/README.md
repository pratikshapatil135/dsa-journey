\# Day 4 - Find Maximum Element



\## Problem

Find the largest element in an array.



\## Example



Array: \[12, 45, 7, 89, 34, 23]



Output: 89



\## Approach

\- Start with the first element as the maximum.

\- Compare every other element with the current maximum.

\- Update the maximum whenever a larger element is found.



\## What I learned

\- Array traversal

\- Comparing elements

\- Updating variables

\- Finding maximum using a loop



\## Time Complexity

O(n)



\## Space Complexity

O(1)
