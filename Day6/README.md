\# Day 6 - Find Minimum Element



\## Problem

Find the smallest element in an array.



\## Example



Array: \[12, 45, 7, 89, 34, 23]



Output: 7



\## Approach

\- Start with the first element as the minimum.

\- Traverse the remaining elements.

\- Compare each element with the current minimum.

\- Update the minimum when a smaller element is found.



\## What I learned

\- Array traversal

\- Comparison of elements

\- Updating variables

\- Finding minimum using a loop



\## Time Complexity

O(n)



\## Space Complexity

O(1)
