# Day 30 - Reverse a String Using Stack

## Problem

Reverse a string using a stack data structure.

## Example

Input: hello

Output: olleh

## Approach

- Create an empty stack.
- Push every character of the string into the stack.
- Pop characters one by one.
- Since a stack follows LIFO, the characters come out in reverse order.
- Build the reversed string.

## What I Learned

- Stack
- LIFO principle
- Push operation
- Pop operation
- String manipulation

O(n)
